# task-tracker — заметки для iOS

## Версия SDK

Проект на **Expo SDK 58** (React Native 0.88, React 19.3, Expo Router 58).

Версию SDK диктует Expo Go из App Store: на iPhone он запускает ровно одну
версию SDK, и на проекте с другой версией не показывает ошибку, а **падает
при открытии**. В октябре 2026 App Store обновил Expo Go до 58 — проект на
SDK 54 перестал открываться даже с пустым экраном. Если Expo Go снова начнёт
вылетать сразу после загрузки, первым делом сверьте `app_version` в отчёте о
сбое (Настройки → Конфиденциальность → Аналитика → Данные аналитики →
`Expo Go-….ips`) с версией `expo` в `package.json`.

Читайте документацию ровно этой версии:
https://docs.expo.dev/versions/v58.0.0/

Не добавляйте модули, которых нет в Expo Go, и ставьте их только через
`npx expo install` — тогда версия совпадёт с той, что зашита в Expo Go.
Проверить список можно так:

```bash
node -e "console.log(Object.keys(require('./node_modules/expo/bundledNativeModules.json')).join('\n'))"
```

В `.npmrc` включён `legacy-peer-deps`: необязательная зависимость
`datetimepicker` тянет `react-native-windows` с другой версией React Native,
и без флага `npm install` и `npm ci` падают на конфликте пиров.

Фреймворков `Speech`, `Vision`, `PencilKit` и
`VNDocumentCameraViewController` в Expo Go нет — они требуют dev-build.

## Главное правило дизайн-системы

**Если элемент есть у системы — берём системный, а не похожий на него.**

Собственный компонент появляется только тогда, когда системного нет вовсе.
Причина не в экономии: системный элемент перекрашивается при «Увеличении
контраста», уплотняется при «Уменьшении прозрачности», растёт вместе с
Dynamic Type, правильно звучит в VoiceOver и меняется с каждой версией
системы сам. Копия ничего этого не знает и стареет с первого дня.

Отсюда следствие для витрины: **системный элемент не рисуется и не заводится
историей в Storybook**. Его место — раздел «Только на устройстве»
(`src/docs/`), где описание и правила применения без картинки.

Действующих исключений три, и все названы.

**Поверхности Opal** (`GlassSurface`, `ScreenBackdrop`, `ThinkingOrb`). Это
визуальный слой продукта, а не замена системных элементов: системного меша,
подсветки и орба не существует.

**Поле поиска** (`src/components/SearchField.tsx`). Системного нет:
`UISearchBar` живёт внутри `UINavigationBar` вместе с крупным заголовком, а
заголовок в продукте встроенный — он стоит в одну строку с кнопками управления
списком. Собрано из системных частей: символ `magnifyingglass`, обычный
`TextInput`, системная типографика.

**Выпадающее меню** (`src/components/Menu.tsx`). Меню с якорем к кнопке — это
`UIMenu` внутри `UIButton`, и отдать его в JS может только нативный модуль,
которого в Expo Go нет. Доступный `ActionSheetIOS` на iPhone всегда приезжает
от нижнего края, то есть через весь экран от кнопки, которая его вызвала.
Собрано из системных частей: жидкое стекло `Glass`, символы SF, метрики
`UIMenu`. Триггер измеряет себя сам и отдаёт прямоугольник — меню растёт из
ближайшего к нему угла.

Системный `ActionSheetIOS` остался там, где он правилен: на вопросах вроде
«что сделать с заметками внутри удаляемой папки», а не на выборе из списка.

## Визуальный слой Opal

Вид приложения — по эталону Opal: **тёмная система, только одна схема**.
Системные элементы остаются системными, но поверх них лежит продуктовый слой,
и обратно на системные значения его не меняют:

- **подложка** — чистый чёрный, а поверхности — прозрачное белое
  (`rgba(255,255,255,0.045)` у карточки), текст — белый с альфой. Серые
  заливки гасят подсветку фона, прозрачность её пропускает;
- **подсветка экрана** (`ScreenBackdrop`) — только у корней трёх вкладок:
  приглушённая серо-зелёная заливка у верхней кромки (замер «Apps» Opal:
  `rgb(50,66,56)` у кромки, к 100pt — в чёрный). Вложенные экраны и шиты —
  чистый чёрный. Шапки прозрачные и без размытия;
- **стекло** (`GlassSurface`) — подложка с альфой, меш из размытых эллипсов и
  градиентный кант. На iOS 26 вместо блюра — системное жидкое стекло,
  прибитое к тёмной схеме; свой кант под ним не рисуется;
- **акцент** — ось лайм → мята → аква (`#DCFEAA` / `#D7FEC0` / `#BBFBE7`).
  Глиф на акцентной заливке чёрный (`onAccent`);
- **главная кнопка** — два вида, как у Opal: стеклянная пилюля с мешем `cta`
  (шаг вперёд) и белая пилюля с чёрной подписью (`variant="white"`,
  подтверждение в шите). Недоступная — тёмная пилюля `#111119` с ободком, а
  не прозрачность. Удаление — пилюля `#18080B` с подписью `#FD7490`;
- **создание** — лаймовый круг «+» 44pt в шапке (`Fab compact`), как на
  «Rules» у Opal. Плавающей кнопки нет. Корни вкладок — крупный заголовок
  слева и кнопки в той же строке (`RootHeader`), системная шапка скрыта;
- **группы строк** — сплошные `#0C0C0C` без меша и канта, радиус 26,
  разделитель 1pt `#191919` с отступом с двух сторон; в шите — `#2B2B2B`
  на шите `#1F1F1F`. Текст строки 17 regular, подпись и значение 15;
- **пустые состояния** — точечный орб на Skia.
- **иконки** — из [box-ui](https://github.com/egorovdnikita/box-ui)
  (`src/vendor/box-ui/icons.ts`, геометрия дословно из
  `packages/icons/src/data/{linear,bold}.json`) под системными именами SF:
  код зовёт `folder`, рисуется знак набора. Стиль — `bold`, кроме стрелок,
  шевронов и поиска: они `linear` и крупнее своей коробки. Имени, которого в
  наборе нет, остаётся SF Symbol. Панель вкладок нативная и SVG не
  принимает — для неё те же глифы растрированы в PNG-шаблоны (`assets/tabs`,
  24pt, @1x–@3x, белым на прозрачном); все вкладки белые, выбранную отличает
  системная линза стекла;
- **«Назад»** — везде одна кнопка `backItem`: стеклянный круг с шевроном, без
  подписи. Стеки вкладок ставят её всем экранам, кроме корневого;
- **фирменный цвет — только главным действиям**: кнопка создания, отправка,
  чекбоксы и выделение. Шапка, иконки строк, меню и инструменты —
  монохромные (`label`). Кнопки «Сохранить» в редакторе нет: заметка
  сохраняется на каждой правке, и кнопка обещала то, что уже произошло;
- **кнопки шапки** — `#121212` с ободком 1pt белый 20%, через `headerItems` в `unstable_headerRightItems` /
  `unstable_headerLeftItems`: системная капсула iOS 26 скрыта
  (`hidesSharedBackground`), под кнопками своё прозрачное стекло. Обычный
  `headerRight` вернёт молочную системную капсулу;
- **края стекла** — где кант рисуем мы (SVG), обрезка идёт дугой
  (`borderCurve: 'circular'`), а не суперэллипсом: иначе кривые расходятся
  и кант на углах срезается ступенькой;
- **стекло карточек, групп и поля поиска** — только свои слои
  (`liquid={false}`): системное жидкое стекло на чёрном светлеет до
  молочного. Системное стекло остаётся у плавающих элементов, вариант `clear`;
- **размеры** — замеры Opal: строка 62pt (с подписью 74), кнопки в шапке
  44pt, чипы 40pt, сегмент 32pt, поле поиска 48pt.

Значения живут в `src/theme/colors.ts` (`opalPalette`) и `src/theme/opal.ts`
(меши, обводки, подложки, подсветки). Меши сняты со скриншотов эталона —
руками не подкручивать. Подложки и канты стекла после проверки на устройстве
сделаны прозрачнее эталона: на OLED эталонные значения читались белёсыми.

## Схема

Одна, тёмная. `ThemeProvider` прибивает `Appearance.setColorScheme('dark')`:
на iOS это `overrideUserInterfaceStyle` окна, и вместе с нашими экранами
тёмными становятся панель вкладок, клавиатура, алерты и меню. Выбора
оформления в настройках нет.

## Чего в продукте нет по постановке

Аккаунта, входа, онбординга, синхронизации, совместной работы, подписки и
любой отправки данных наружу. Всё хранится на устройстве. Это не «пока не
сделано» — это решение о продукте.

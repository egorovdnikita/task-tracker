# task-tracker

Приложение для локальных заметок на iOS: текст, чек-листы, голосовые записи,
сканы и рисунки. Поддерживает папки, теги, поиск, напоминания и корзину.
Аккаунта и синхронизации нет. Экспорт текста запускается пользователем через системное меню «Поделиться».

## Стек

TypeScript 6, React 19.3, React Native 0.88, Expo SDK 58, Expo Router 58,
Zustand 5, AsyncStorage. Витрина компонентов: Storybook 10, Vite 8,
react-native-web. Иконки box-ui с резервными SF Symbols.

## Запуск

```bash
npm ci
npm start
```

На iPhone откройте совместимый с SDK 58 Expo Go и отсканируйте QR-код
штатной Камерой. Если телефон на LTE, запустите туннель:

```bash
npx expo start --tunnel --clear
```

Камера, микрофон и локальные уведомления запрашиваются при использовании.
Speech, Vision и PencilKit в Expo Go недоступны: расшифровки, OCR и нажима стилуса нет.
Оформление — Finch, одна схема со светлыми системными элементами; вкладки, шапки, фильтры и переключатели используют геометрию Finch. Клавиатура и открытые системные пикеры проверяются на iOS.

## Экраны

- `/notes` — заметки: список, сетка, поиск, фильтры и множественный выбор.
- `/create`, `/note/[id]` — создание и редактор с автосохранением.
- `/folders`, `/folders/[id]`, `/folder`, `/move` — папки, содержимое, правка и перенос.
- `/folders/trash` — восстановление и окончательное удаление.
- `/reminder`, `/reminders` — срок заметки и общий список напоминаний.
- `/more`, `/more/stats`, `/more/notifications` — настройки, статистика и уведомления.
- `/note-info` — сведения о заметке.
- `/capture/voice`, `/capture/scan`, `/capture/sketch` — запись, съёмка и рисунок.

## Проверки и сборка

```bash
npm run typecheck
npx expo export --platform ios
npm run build-storybook
```

CI проверяет типы и собирает витрину; GitHub Actions публикует её из `main`:
[витрина компонентов](https://egorovdnikita.github.io/task-tracker/).

```bash
npm run storybook
```

Витрина доступна на `http://localhost:6006`. Она показывает общие компоненты,
а не полноценное iOS-приложение. Системные элементы описаны в `src/docs/`.

## Структура

- `app/` — маршруты Expo Router.
- `src/components/`, `src/theme/` — компоненты и токены Finch.
- `src/store/`, `src/features/`, `src/utils/` — хранение и логика заметок.
- `src/docs/`, `.storybook/` — документация и витрина.
- `docs/AUDIT_LOG.md` — журнал аудита; остальные аудиты сохраняют исторический контекст.

Правила системных компонентов и сознательные исключения описаны в [AGENTS.md](AGENTS.md).

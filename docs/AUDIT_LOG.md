## 2026-11-27 — аудит токенов Box UI и исправления

База: `93642c92cd067da9337bb1740706aab90491fb24`. Это полный аудит области
дизайн-токенов по прямому запросу, без повторного логического аудита приложения.
Прочитаны AGENTS.md, CLAUDE.md и предыдущие записи журнала.
Источник Box UI: `9cff5edcef3878d56c6d4241eb16cea8635f0f09`, только чтение.
Полный реестр: `token-inventory.json`; соответствия, конфликты и команды:
[TOKEN_SYNC.md](TOKEN_SYNC.md).

### Найдено и исправлено

- `src/theme/metrics.ts`: локальная копия шкал spacing/radius/controlHeight
  не имела связи с Box UI. Совместимые значения теперь ссылаются на генерацию.
- В стилях экранов/компонентов/историй повторялись совместимые примитивы.
  Всего заменено 85 литералов по назначению (отступы, радиусы, размеры),
  без изменения значений. Иконки и их геометрия не менялись.
- Повторялись краски акцента Opal, фона шита, трека диаграммы, белого/чёрного.
  Добавлены общие локальные роли; белый/чёрный используют примитивы Box UI.
- Не было воспроизводимой синхронизации и контроля расхождений: добавлены
  генератор, снимок SHA-256 коллекций, реестр выражений и проверки в CI.
- Сломанных используемых aliases не обнаружено; корректность новых ссылок
  дополнительно контролируется TypeScript. Веб-CSS токенов в RN не импортируется.

### Сознательно не трогаем

  Low/Medium/High, радиусов 26/999, поверхностей и материалов перечислены

- Локальные значения без эквивалента, вычисляемая геометрия и системные
  метрики iOS остаются документированными исключениями. Новые режимы,
  экраны, контент и механики не добавлялись.
- Box UI, иконки, зависимости SDK и посторонняя логика не изменялись.

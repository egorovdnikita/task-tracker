# Finch — перенос макетов в приложение

2026-11-27. База до изменения: `dbe0797a6331fd8ad9edaac59f1ae94bfb4f8ef6`.
Режим: реализация утверждённых мобильных макетов, а не аудит прежнего Opal.
Файл макетов: страница «task-tracker · Finch», доска `376:662`, 20 состояний.

## Что перенесено

- Палитра Finch: бумага `#FFFFFF`, текст `#1A1A1A`, подписи `#A1A1A6`,
  вторичные заливки `#F2F2F3`, главное действие `#C4FB6F`.
- Пять заливок фона воспроизведены SVG: линейный градиент и четыре
  радиальных слоя с координатами, цветами и прозрачностями из макета.
- Общие компоненты: белые карточки, строки-пилюли 72/60, радиусы 32,
  стеклянные кнопки шапки, поиск, пустые состояния, числовые карточки.
- Handjet встроен локально; статический экземпляр ELGR=1, ELSH=8, wght=400
  из официального google/fonts, лицензия OFL рядом с файлом.
- Главная: живой счётчик, поиск из шапки, создание 56pt; сортировка и смена
  списка/сетки доступны нажатием на название «Заметки».
- Общий слой подключён к папкам, настройкам, статистике, редактору текста
  и чек-листа, сведениям, созданию, папке, напоминанию, всем напоминаниям,
  переносу, уведомлениям, корзине, голосу, скану, рисунку и пустым спискам.
  Редактор получил белую бумагу. Сохранение данных и медиа не переписано.

## Границы первого переноса

Это первая реализация, а не подтверждение попиксельной готовности 20 экранов.
Первоначальное исключение для нативных вкладок, сегмента, Switch и formSheet
снято прямым указанием пользователя 2026-11-27. Теперь их геометрия Finch:
капсула204×52, вкладки44, фильтры32, переключатель51×31, шапка safe area+68.
Формы открываются на весь экран; окно создания остаётся над клавиатурой.
Системными остаются ввод, клавиатура, открытые пикеры даты/времени, разрешения
и механика стека. Камера остаётся живой камерой.
Новый контент и демонстрационные заметки в хранилище не добавлены.

## Проверки

- `npm run typecheck` — пройден.
- `npm run build-storybook` — пройден.
- `npm run tokens:check`, `npm run tokens:test` — пройдены (1 тест).
- `npx expo export --platform ios` — пройден, Hermes bundle 5.5 MB.
- Своими глазами через нативный CUA в уже открытом Chrome просмотрены
  **2 веб-превью компонентов**: главная и пустое состояние, 390×844.
  Градиент, Handjet, карточки, строки и основная кнопка отрисовались.
  Это Storybook с mock-данными, а не запуск нативной навигации.
- Браузерное подключение CUA вернуло `browser access host is unavailable`;
  нативный доступ к Chrome работает. Playwright/Orca не применялись.
- iOS Simulator недоступен: `xcrun` не находит `simctl`. На физическом iPhone
  приложение этой сессией не просмотрено. Все 20 состояний и соседние блоки
  **на устройстве ещё не проверены**, отсутствие визуальных регрессий не заявлено.

## Запуск и откат

`npx expo start --tunnel --clear --port 8081`; QR брать у текущего сервера,
адрес туннеля может меняться. В Expo Go открыть проект заново, чтобы
применились схема системных элементов и новый шрифт.
Для точного отката визуального эксперимента — отменить коммит Finch целиком,
не откатывая предыдущую синхронизацию Box UI.

## Нативный визуальный слой — после `312e351`

UITabBar и UISegmentedControl заменены FinchTabBar и общим SegmentedControl,
UISwitch — FinchSwitch. FinchHeader задаёт центрированный заголовок17 и
кнопки44 без капсулы UINavigationBar. Все полноэкранные формы используют
`card`, inset прокрутки задаётся через реальную высоту собственной шапки.
Контексты и API навигации импортируются из публичных экспортов Expo Router58.
Закрытые поля даты/времени — обычные строки62, открытый редактор срока —
системный picker внутри локального диалога.

Проверены в Chrome пользователя: три вкладки, открытие/закрытие формы папки,
статистика и возврат, скрытие панели на вложенном маршруте; превью390×844
главной с фильтрами и новой панелью, переключатель с изменением состояния.
Это проверка веб-отрисовки общего кода, а не визуальная приёмка iPhone.
TypeScript, iOS export, Storybook build, проверка токенов и6 тестов пройдены.
Все20 экранов на устройстве ещё не проверены; полное1:1 не заявляется.

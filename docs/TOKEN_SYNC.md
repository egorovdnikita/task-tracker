# Токены task-tracker и Box UI

Источник: соседний checkout `../box-ui`, `tokens/figma/*.txt`, состояние
`9cff5edcef3878d56c6d4241eb16cea8635f0f09` на 2026-11-27.
Box UI используется только для чтения. CSS `var()` из веб-пакета не подходит
React Native: здесь генерируются числовые примитивы и две непрозрачные краски.
Иконки исключены из аудита и синхронизации.

## Команды

- `npm run tokens:check` — сравнить генерацию и SHA-256 всех неиконных
  коллекций с текущими локальными исходниками Box UI; проверить реестр проекта.
- `npm run tokens:sync` — воспроизвести `src/vendor/box-ui/primitives.ts` и
  `docs/box-token-source.json`. После команды обязательно просмотреть diff:
  изменение upstream не является разрешением менять внешний вид продукта.
- `BOX_UI_DIR=/path/to/box-ui npm run tokens:check` — другой путь источника.
- `npm run tokens:inventory` — обновить реестр после проверки новых значений.
- `npm run tokens:test` — тесты воспроизводимости и обнаружения дрейфа.
- `node scripts/verify-token-values.mjs 93642c9` — структурная проверка этой
  миграции: раскрывает ссылки и сравнивает AST с базой, исключая новые импорты,
  комментарии и регистр/краткую запись HEX. Проверяет также соседний код.

Обычная сборка не требует Box UI рядом: результат генерации хранится в git.
CI проверяет реестр, тесты генератора и TypeScript. Свежесть относительно
внешнего checkout проверяется локальной командой `tokens:check`, не CI.
Генератор не устанавливает зависимости и не запускает сборку в Box UI;
неизвестный синтаксис, пропавшие примитивы и дубли останавливают генерацию.
Типы `as const` сохраняют литеральные значения и проверяют все ссылки импортов.

## Что связано

85 числовых литералов в метриках, стилях компонентов, экранов и историй
заменены примитивами того же назначения: spacing → spacing, radius → rounding,
фиксированные размеры → size. Локальные семантические имена `spacing.lg`,
`radius.sm`, `controlHeight.button` сохранены; одноимённые размеры Box UI
не считаются семантическими aliases продукта. Значения до и после одинаковы.
Чёрный/белый берутся из `prim-color:color/alpha/{black,white}/100` через
локальные роли. Повторы акцента, фона шита, трека диаграммы и специальных
заливок вынесены в `src/theme/localColors.ts` и используются палитрой,
поверхностями и компонентами совместно.

## Конфликты и локальные токены — сохраняем внешний вид

| Роль | task-tracker | Box UI / причина исключения |
| --- | --- | --- |
| Фон страницы | `#000000` | `sys-theme:surface/base/fill/page`, Dark → `#0a0a0a`; локальная роль использует чёрный примитив, но не alias страницы Box UI |
| Основной текст | `#FFFFFF` | `surface/base/content/strong`, Dark → `#fafafa`; локальная роль использует белый примитив |
| Вторичный текст | белый 66% | `surface/base/content/muted`, Dark → `#a3a3a3`; непрозрачный серый меняет наложение |
| Группы и шиты | `#0C0C0C`, `#2B2B2B`, `#1F1F1F` | Поверхности Opal; роли raised/layer-subtle Box UI дают другие значения |
| Акцент | `#DCFEAA`, `#D7FEC0`, `#BBFBE7` | Deep/Bright/Monochrome Box UI не являются осью Opal; ближайшие цвета не подбираются |
| Статусы | destructive `#FC6578`, success `#05D6B4` | Семантика Opal сохранена, цветовые шкалы статусов Box UI не подставляются |
| Типографика | SF Pro/System; body `17/22`, tracking `-0.41` | Все семейства Box UI — Inter; responsive body/l `16/20`, tracking `0`. Вся шкала SF, веса и коэффициенты остаются системными локальными токенами, даже при совпадении отдельных чисел |
| Скругления | group `26`, pill `999` | `26` отсутствует; full Box UI `9999`. Остальные локальные имена не привязаны к Low/Medium/High: это изменило бы размеры |
| Высоты | row `62`, detail `74`, tab bar `54` | Нет соответствующих size-примитивов; замеры Opal/iOS |
| Кант/тени | hairline `0.5`, обводки `1`; тени opacity `0.12/0.16/0.24/0.28` | Нет соответствующего набора семантических токенов теней/толщин; локальные профили компонентов |
| Прозрачности | текст `0.66/0.42/0.22`, стекло `0.04–0.14`, градиентные канты | Сетки альфа Box UI не воспроизводят эти значения и материалы; локальные Opal-токены |
| Материалы и меши | `materials.ts`, `opal.ts`, ThinkingOrb | UIKit BlurTint, Liquid Glass, Skia и замеры мешей не имеют эквивалента в Box UI |

Светлые пары системной палитры — fallback API и витрины, не вторая тема продукта.
ThemeProvider сохраняет одну тёмную схему. Режимы Box UI не добавляются в продукт.
Динамическая геометрия (половина размера круга, размеры canvas, safe area,
проценты, SVG-координаты), нулевые сбросы, размер фотографии, метрики камеры,
плотность waveform и параметры анимаций сохраняются локально: размерный
примитив с тем же числом не означает ту же роль. Специальные интервалы,
радиусы 1/13/29 и размеры вне шкалы не округляются.

`docs/token-inventory.json` хранит точные выражения с файлом и свойством,
включая оставшиеся локальные литералы, ссылки и вычисления. Он охватывает
85 TS/JS-файлов app/src/.storybook (исключены vendor и Symbol с иконками),
1257 выражений на момент аудита. Реестр — контроль изменений, а не доказательство
семантической правильности: его обновление требует просмотра diff.
В `app.json` тёмная схема и чёрный фон — статические значения manifest;
цвет Android adaptiveIcon относится к исключённым иконкам. HTML head не содержит
визуальных значений. Растровые ресурсы, содержимое заметок и историческая
документация не являются токенами интерфейса.
